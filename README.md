# BananaTel

An Impossible Creatures mod based on Tellurian and using assets from other mods like Dino Dawn.

## What's new
- Expanded creature roster (listed below).
- Balancing changes to creature stats, costs, and progression.

## Install (Steam)
1. Open Steam.
2. Select Impossible Creatures in your library.
3. Click the cog icon on the game page.
4. Choose **Manage** → **Browse local files** (or **Open local files**).
5. Paste the mod into the local files folder.
